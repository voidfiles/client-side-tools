# Systems Modeling Playground

A browser-only, language-first system dynamics playground in the spirit of
[lethain/systems](https://github.com/lethain/systems), built from the research
report in [`research/systems-modeling-playground.md`](../../research/systems-modeling-playground.md).

## What it does

- **A text language for stock-and-flow models** — a superset of the
  lethain/systems notation. Models written for the original Python tool run
  here unmodified and produce the same per-round tables (verified against the
  original package's output — see `tests/`).
- **Language-server-like feedback while typing**: domain-aware diagnostics
  ("reference to undefined stock", "a leak can't drain an infinite stock",
  "initial values form a cycle"), completion of stock/auxiliary names and
  builtins with signatures, and hover documentation including a sparkline of
  the hovered stock's last run.
- **Live simulation**: each edit is debounced ~300 ms and run in a Web Worker
  (with `Worker.terminate()` on a 2 s deadline as the runaway backstop), then
  rendered as a uPlot chart and a per-round table with CSV export.
- **Share by URL**: the model + settings are deflate-compressed into
  `location.hash` — no server involved.

## The language

Everything from lethain/systems (`docs/spec.md` semantics, including the
discrete-rounds engine's quirks: reversed flow processing order, deferred
destination additions, flooring in Conversion/Leak), plus:

- **Auxiliaries**: `Name = expression`, recomputed every round.
- **Real expressions**: standard operator precedence (the one deliberate
  divergence — the original evaluates strictly left-to-right), parentheses,
  `^`, comparisons, `AND OR NOT`, `IF…THEN…ELSE`.
- **An XMILE-flavored standard library**: `ABS INT ROUND MIN MAX MOD SQRT EXP
  LN LOG10 SIN COS TAN PI SAFEDIV`, `TIME DT STARTTIME ENDTIME`,
  `STEP PULSE RAMP`, and seeded `RANDOM NORMAL LOGNORMAL EXPRND POISSON`
  (one model-level seed; same source + same seed ⇒ identical table).

## Architecture

| File | Role |
|---|---|
| `lang.js` | Tokenizer, parser, analyzer (symbols + diagnostics), builtin catalog. One analyzer feeds the linter, completion, and hover — the "language server lite" pattern. |
| `engine.js` | Discrete-rounds interpreter, compatible with lethain/systems. Dependency-free; runs in the worker and under Node. |
| `sim-worker.js` | Module worker: analyze → run → transfer results back as a `Float64Array`. |
| `main.js` | CodeMirror 6 wiring, worker management, uPlot chart, table, CSV, share-by-URL, examples. |
| `tests/` | `node tests/run-tests.mjs` — fixtures generated by running the original Python package over its `examples/` corpus plus edge cases. |

No build step: CodeMirror 6 and uPlot load as pinned ES modules from CDNs via
an import map (the `esm.sh/*` external-deps form guarantees a single shared
`@codemirror/state` instance). A hand-written parser is used instead of a
generated Lezer grammar to keep the repo's no-codegen convention; the DSL is
line-oriented, so error tolerance comes free.

node tools/systems-playground/tests/run-tests.mjs
