Language reference

Stocks: declared up front

# Name(initial, max)? "description"? visible: bool?
Recruiters(3)   "Recruiting team"
Pipeline(0, 50) "Capped at 50"
Departures      "Hidden from chart" visible: false
[Candidates]    "Infinite boundary stock (never shown)"
  • Every stock is declared before the flows that use it.
  • Descriptions show up in hover docs and autocomplete.
  • visible: false keeps a stock out of the chart; it stays in the table and CSV.

Flows & auxiliaries

# source > destination @ rate
[Candidates] > Screens @ Recruiters * 3
Screens > Onsites @ 0.5        # decimal = Conversion
Staff > Departures @ Leak(0.1) # fraction leaks out
a > b @ Rate(2)                # explicit Rate

# auxiliaries: recomputed every round
ChurnRate = IF Active > 500 THEN 0.08 ELSE 0.04
  • Rate(n) — up to n units move per round.
  • Conversion(f) — drains the source; destination gains ⌊source·f⌋.
  • Leak(f) — moves ⌊source·f⌋, source keeps the rest.
  • Standard operator precedence, parentheses, ^, comparisons, AND OR NOT, true/false, IF…THEN…ELSE, trailing # comments.
  • All randomness is seeded — identical seed ⇒ identical run.

Builtin functions (XMILE-flavored)

  • Math: ABS INT ROUND MIN MAX MOD SQRT EXP LN LOG10 SIN COS TAN PI SAFEDIV
  • Time: TIME DT STARTTIME ENDTIME
  • Test inputs: STEP(h, start), PULSE(mag, first, interval?), RAMP(slope, start)
  • Random: RANDOM NORMAL LOGNORMAL EXPRND POISSON
