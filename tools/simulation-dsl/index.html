Simulation DSL

A text language for the whole scottfr/simulation toolkit — stocks, flows, variables, converters, and full agent-based modeling (agents, states, transitions, populations, actions). What you write compiles straight onto the simulation engine, which runs the model right here in your browser. Pick an example, edit, and the chart and table update live. Equations use the engine's own formula language ([References], {units}, if … then … else end if).

Language reference

Settings & stock-and-flow

sim { start: 0, length: 50, step: 0.5,
      units: 'Years', algorithm: RK4,  # or Euler
      plot: [stock] }    # default: stocks only

@Prey { initial: 400, nonNegative: true,
        units: "Prey" }
@Belt { initial: 0, type: Conveyor, delay: 5 }
@Empty                  # no body → initial 0
$Rate = 0.25 { units: "1 / Years" }

# A flow is just Source -> Target (_ = outside),
# auto-named SourceToTarget; Name: overrides.
_ -> Prey { rate: "[Prey] * [Rate]", nonNegative: true }
Deaths: Prey -> _ = "[Prey] * 0.1"

Converters & links

converter Growth {
  input: Population,      # or: input: time
  interpolation: Linear,  # or Discrete
  points: (0, 2) (5000, 1) (10000, 0)
}

# links are inferred from every [Reference]
# in an equation; declare extra ones with:
link Rate -> Births

References resolve case-insensitively; quote names with spaces: [Prey Birth Rate].

Agent-based modeling

agent Person {
  state Healthy  { startActive: true }
  state Infected { startActive: false }
  transition Catch: Healthy -> Infected {
    trigger: Probability, value: 0.05 }
  transition Heal: Infected -> Healthy {
    trigger: Timeout, value: "{14 days}" }
}
population Pop { size: 200, base: Person }

action Reset { trigger: Timeout, value: 30,
               do: "[Healthy] <- true" }

Chart agent counts with $"Num Infected" { value: "Count([Pop].FindState([Infected]))" } and plot: [variable].
